# AI Question Answerer

A Python-based AI application built with FastAPI and NVIDIA's OpenAI-compatible API. It accepts questions through an HTTP endpoint and returns answers generated by a large language model.

## Features

- Integrates with NVIDIA's LLM API using the OpenAI Python SDK
- Exposes a REST API using FastAPI
- Validates incoming questions using Pydantic
- Handles authentication, rate-limit, and API errors
- Includes automated tests using pytest and FastAPI's TestClient

## Tech Stack

- Python
- FastAPI
- NVIDIA API
- OpenAI Python SDK
- Pydantic
- Pytest
- HTTPX

## Setup

### 1. Clone the repository

```bash
git clone https://github.com/Manikanta-Chilaka/ai-question-answerer.git
cd ai-question-answerer
```

### 2. Create and activate a virtual environment

On Windows PowerShell:

```powershell
py -m venv .venv
.\.venv\Scripts\Activate.ps1
```

### 3. Install dependencies

```bash
python -m pip install -r requirements.txt
```

### 4. Configure your API key

Create a `.env` file in the project root:

```dotenv
NVIDIA_API_KEY=your_nvidia_api_key
```

Never commit your `.env` file or expose your API key.

### 5. Start the server

```bash
python -m uvicorn app:app --reload
```

Open the interactive API documentation at:

http://127.0.0.1:8000/docs

## API Usage

### Health check

`GET /`

Example response:

```json
{
  "message": "AI Question Answerer API is running"
}
```

### Ask a question

`POST /ask`

Request body:

```json
{
  "question": "Explain retrieval augmented generation in simple words."
}
```

The response contains the original question and the generated answer.

## Run Tests

```bash
python -m pytest -v
```

The automated tests cover the health endpoint, request validation, successful responses using a mock, and rate-limit error handling.
